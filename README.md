# ZedG Scoop Bucket

[ZedG](https://github.com/wenyinos/ZedG)（Zed 编辑器简体中文版）的 Scoop bucket。

## 安装

```powershell
scoop bucket add zedg https://github.com/wenyinos/scoop-zedg
scoop install zedg
```

## 更新

```powershell
scoop update
scoop update zedg
```

Manifest 由 ZedG 仓库的 Release 流程自动更新（ZedG 仓库 `.github/workflows/05-update-scoop.yml`），发布新版本后通常几分钟内生效。
